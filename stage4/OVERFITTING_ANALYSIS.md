# Анализ проблемы переобучения и решения

## 🚨 Проблема: Метрики деградируют при увеличении эпох

### Симптомы переобучения (overfitting):
- **Train loss** уменьшается стабильно
- **Validation loss** сначала уменьшается, затем начинает расти
- **Метрики качества** (BERTScore, CodeBLEU, BLEU, ROUGE, RUBY) достигают пика на ранних эпохах, затем падают
- Лучшие результаты на 1-2 эпохах, затем деградация

### Почему это происходит:

1. **Слишком сложная модель** - 74 кодовых фичи + большая сеть
2. **Недостаточная регуляризация** - низкий dropout (0.2)
3. **Отсутствие early stopping** - обучение до конца несмотря на деградацию
4. **Высокий learning rate** - модель "перепрыгивает" оптимум
5. **Недостаток данных** - модель переобучается на тренировочный набор

## ✅ Решения

### 1. Увеличение dropout
```python
# Было: dropout=0.2
# Стало: dropout=0.4
self.classifier = EnhancedClassifierWithFeatures(
    dropout=config.get('dropout', 0.4)
)
```

### 2. Early stopping
```python
patience = 5  # Остановка после 5 эпох без улучшения (увеличено для стабильности)
if patience_counter >= patience:
    print("[STOP] Early stopping")
    break
```

### 3. Learning rate scheduler
```python
scheduler = torch.optim.lr_scheduler.ReduceLROnPlateau(
    optimizer, mode='max', factor=0.5, patience=2
)
# Уменьшает LR вдвое каждые 2 эпохи без улучшения
```

### 4. Увеличение weight decay
```python
# Было: weight_decay=1e-2
# Стало: weight_decay=1e-3
optimizer = torch.optim.AdamW(..., weight_decay=1e-3)
```

### 5. Снижение learning rate
```python
# Было: lr=2e-5
# Стало: lr=1e-5
```

### 6. Уменьшение сложности модели
```python
# Было: hidden_dim=768
# Стало: hidden_dim=512
```

### 7. Увеличение batch size
```python
# Было: batch_size=8
# Стало: batch_size=16
# Более стабильные градиенты
```

## 🔍 Диагностика

### Признаки переобучения:
- Train loss << Val loss
- Метрики на train → 1.0, на val → падают
- Большие колебания метрик между эпохами

### Признаки недообучения:
- И train, и val метрики низкие
- Медленное улучшение или отсутствие прогресса

### Баланс:
- Train и val метрики близки и постепенно растут
- Стабильное улучшение без резких скачков

## 🎯 Рекомендации

1. **Всегда используйте early stopping** - предотвращает переобучение
2. **Начинайте с большего dropout** - лучше перерегуляризовать, чем недорегуляризовать
3. **Мониторьте соотношение train/val метрик** - должно быть близким к 1
4. **Используйте learning rate scheduler** - адаптивное обучение
5. **Экспериментируйте с batch size** - влияет на стабильность градиентов

Теперь система должна показывать стабильный рост метрик или хотя бы не деградировать! 🎉
